1. ข้อมูลอ้างอิง Shipment กำลังดำเนินการ

พบข้อมูล SO/DO ไม่ตรงกัน — ระงับการโหลดและส่งให้ผู้มีอำนาจตรวจสอบ (ใบงานผิด)

ข้อมูลเริ่มต้นเป็น Mock Data เพื่อทดสอบเท่านั้น ยังไม่มีการเชื่อมต่อ SAP หรือฐานข้อมูลจริง

2. เอกสารคนขับรถ / Pre-Loading

ถ่ายภาพเอกสารคนขับรถ

เช่น ใบส่งสินค้า, ใบงาน, เอกสารอ้างอิง SO/DO และเอกสารรถ

ตรวจสอบสินค้าก่อนโหลด — 1 Pallet = 4 ถัง

ตรวจครบทุกหัวข้อของถังแต่ละใบก่อนจึงจะถือว่า Pallet สมบูรณ์ หากไม่ผ่านข้อใดให้ระงับและส่งผู้มีอำนาจตรวจสอบ

3. ตรวจสอบตู้ Container ก่อนใช้งาน

ภาพสภาพตู้ก่อนโหลด

ถ่ายภาพภายในตู้ พื้น ผนัง เพดาน ประตู และสภาพความสะอาด

4. Loading — รูปแบบภาพระหว่างโหลด

ตัวอย่าง Pattern ขั้นต่ำ: (1) ภาพก่อนเริ่มโหลด (2) ภาพระหว่างจัดเรียง (3) ภาพแต่ละแถว/ชั้น (4) ภาพเมื่อโหลดครบก่อนปิดตู้
